# Interface assets

- `checkers-sixty60.png`: Checkers Sixty60 brand mark from [Bolton Technical's Checkers Sixty60 case study](https://www.boltontechnical.co.za/pages/signal-booster-solution-checkers-sixty60). [Original image](https://cdn.shopify.com/s/files/1/0014/7023/4659/files/unnamed_480x480.png?v=1655122554).
- Brand layout reference: [Rainmaker Checkers organic social media specification](https://rainmakermedia.co.za/content/dam/rainmakermedia/styleguides/Rainmaker-Checkers-Specification-Sheet-Social-Media.pdf).
- `bike-life.svg`: original monochrome side-view delivery-bike drawing for this game's HUD.

- Opening rider: original AI-generated six-pose motorcycle rider sprite sheet, with a transparent-background refinement. Generated for this game, November 2026. rider-wave-transparent.png is the active animation asset; the logo remains the existing brand asset.

- start-screen-detailed.png: high-resolution still recreation of the user-supplied opening reference, preserving its horizontal wordmark composition. Current opening artwork; replaces the animated rider layout.

- assets/audio: original synthesized game sound samples selected by the user from the local 27-option soundboard. City ambience is excluded. The continuous bike loop derives from the selected option 3 timbre. See AUDIO.md and AUDIO-CHOICES.txt.

- assets/audio/embedded.js: generated base64 copies of the eight selected local WAV files, for direct file:// loading without fetch.
